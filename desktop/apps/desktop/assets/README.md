# Application assets

The PFSAA icon artwork (`pfsaa-icon.*`) is project-specific artwork
distributed under the repository's MIT License. Legacy upstream desktop assets remain
only for source history compatibility and are not referenced by current builds.
`pfsaa-miniwindow.node` is a local build output generated from
`apps/desktop/native/miniwindow.mm` and is excluded from Git.

Do not add third-party logos, fonts, screenshots, or artwork here without also
recording their source, license, and redistribution terms.
