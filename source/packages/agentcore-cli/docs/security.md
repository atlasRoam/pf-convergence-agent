# 安全边界

agentCore 进程、工具和扩展以启动它的用户权限访问本地文件、进程和网络；项目信任控制资源加载，不是沙箱。需强隔离时使用操作系统权限或独立容器/虚拟机，限制可见工作目录与凭据，并审阅模型生成的命令。

根启动脚本把 cwd 固定为 `runtime/`，并为兼容既有用户数据以 `AGENTCORE_*` 指向 `runtime/.agent/` 配置和会话目录；它不自动合并、迁移或删除 `.agentcore`。根入口禁用自动扩展、Skill、模板与上下文文件发现，并显式注入 PFNT Skill 和凭据防护。这是产品默认配置，不是强制访问控制；用户显式传入资源仍可能执行代码。直接包入口没有这些注入和隔离。`--approve` 也不能授予安全沙箱。

不要把 `auth.json`、真实运行案例、模型输出或 HTML 会话导出写入文档和公开日志。CLI 的 `auth print-*` 会直接打印秘密；仅在受控进程内使用。受信任资源之外的文本和工具输出都可能包含提示注入。
